# 漫畫收藏功能

## 📖 功能概述

漫畫收藏是 Pocketit 的核心功能之一,讓使用者能夠有效地管理和追蹤他們的漫畫閱讀歷程。無論是想要記錄正在追的連載、整理已完成的作品,還是建立待看清單,漫畫收藏功能都能滿足您的需求。

## ✨ 核心特色

- 📚 **完整的漫畫管理**: 新增、編輯、刪除漫畫項目
- 📊 **進度追蹤**: 記錄閱讀章節/卷數,視覺化顯示完成度
- 🏷️ **狀態分類**: 想看、閱讀中、已完成、暫停、放棄
- ⭐ **評分與筆記**: 為漫畫評分(1-10 分)並記錄個人心得
- 🔍 **智慧搜尋**: 關鍵字搜尋、多條件篩選、多種排序方式
- 💾 **本地儲存**: 使用 LocalStorage 自動儲存,無需註冊即可使用
- 🎨 **像素風格**: 復古 8-bit 美學,搭配柔和莫蘭迪色系
- 🌓 **深色模式**: 自動偵測系統偏好,舒適的閱讀體驗
- 📱 **響應式設計**: 完美支援桌面、平板和行動裝置

## 🚀 快速開始

### 新增第一本漫畫

1. 進入漫畫收藏頁面
2. 點擊「新增漫畫」按鈕
3. 填寫漫畫資訊:
   - **漫畫名稱** (必填): 例如「ONE PIECE」
   - **作者** (選填): 例如「尾田榮一郎」
   - **狀態** (必填): 選擇「想看」、「閱讀中」等
   - **總章節數/卷數** (選填): 例如「1000 章」
   - **已閱讀章節數** (選填): 例如「500 章」
   - **評分** (選填): 1-10 分
   - **標籤** (選填): 例如「冒險」、「熱血」
   - **筆記** (選填): 記錄個人心得
4. 點擊「儲存」完成新增

### 更新閱讀進度

1. 在漫畫卡片上找到「更新進度」按鈕
2. 輸入最新的已閱讀章節數
3. 系統自動計算完成百分比
4. 當進度達到 100% 時,狀態自動更新為「已完成」

### 搜尋與篩選

- **關鍵字搜尋**: 在搜尋框輸入漫畫名稱或作者
- **狀態篩選**: 選擇特定狀態(如「閱讀中」)查看相關漫畫
- **評分篩選**: 篩選特定評分範圍的漫畫
- **標籤篩選**: 依標籤分類查看
- **排序**: 依新增時間、名稱、評分或更新時間排序

## 📋 資料欄位說明

### 必填欄位

| 欄位     | 說明       | 範例      |
| -------- | ---------- | --------- |
| 漫畫名稱 | 漫畫的標題 | ONE PIECE |
| 狀態     | 閱讀狀態   | 閱讀中    |

### 選填欄位

| 欄位              | 說明               | 範例                  |
| ----------------- | ------------------ | --------------------- |
| 作者              | 漫畫作者名稱       | 尾田榮一郎            |
| 總章節數/卷數     | 漫畫的總章節或卷數 | 1000 章 或 100 卷     |
| 已閱讀章節數/卷數 | 已閱讀的章節或卷數 | 500 章 或 50 卷       |
| 評分              | 個人評分,1-10 分   | 9                     |
| 標籤              | 分類標籤,可多選    | 冒險, 熱血, 友情      |
| 筆記              | 個人心得和備註     | 劇情精彩,角色刻畫深刻 |

## 🎯 狀態說明

| 狀態   | 說明               | 使用時機             |
| ------ | ------------------ | -------------------- |
| 想看   | 計劃閱讀但尚未開始 | 加入待看清單         |
| 閱讀中 | 正在閱讀           | 追連載或閱讀進行中   |
| 已完成 | 已閱讀完畢         | 看完全部章節         |
| 暫停   | 暫時停止閱讀       | 等待更新或暫時擱置   |
| 放棄   | 決定不再繼續閱讀   | 不符合喜好或其他原因 |

## 💡 使用技巧

### 1. 善用標籤分類

建立自己的標籤系統,例如:

- **類型標籤**: 冒險、戀愛、懸疑、科幻、奇幻
- **風格標籤**: 熱血、治癒、搞笑、黑暗
- **來源標籤**: 週刊少年 Jump、月刊、網路連載
- **狀態標籤**: 已完結、連載中

### 2. 定期更新進度

- 每次閱讀後立即更新進度,避免遺忘
- 利用進度百分比掌握閱讀狀況
- 設定總章節數以啟用進度條視覺化

### 3. 記錄心得筆記

- 記錄印象深刻的情節或角色
- 寫下推薦理由,方便日後分享
- 記錄閱讀日期和當時的心情

### 4. 活用搜尋與排序

- 使用「最近更新」排序找到最近閱讀的漫畫
- 使用「評分」排序找出最喜歡的作品
- 結合多個篩選條件精準查找

## 🔧 技術實作

### 資料結構

```typescript
interface Manga {
  id: string; // UUID
  title: string; // 漫畫名稱
  author?: string; // 作者
  status: MangaStatus; // 狀態
  totalChapters?: number; // 總章節數
  readChapters: number; // 已閱讀章節數
  rating?: number; // 評分 (1-10)
  tags: string[]; // 標籤
  notes?: string; // 筆記
  createdAt: string; // 建立時間 (ISO 8601)
  updatedAt: string; // 更新時間 (ISO 8601)
}

type MangaStatus = "want-to-read" | "reading" | "completed" | "on-hold" | "dropped";
```

### LocalStorage 結構

```json
{
  "pocketit_manga_v1": {
    "version": "1.0.0",
    "mangas": [
      {
        "id": "uuid-1",
        "title": "ONE PIECE",
        "author": "尾田榮一郎",
        "status": "reading",
        "totalChapters": 1000,
        "readChapters": 500,
        "rating": 9,
        "tags": ["冒險", "熱血"],
        "notes": "劇情精彩",
        "createdAt": "2026-01-26T12:00:00Z",
        "updatedAt": "2026-01-26T12:00:00Z"
      }
    ]
  }
}
```

### 狀態管理

使用自訂 Hook `useMangaStore` 管理狀態:

```typescript
const {
  mangas, // 所有漫畫
  addManga, // 新增漫畫
  updateManga, // 更新漫畫
  deleteManga, // 刪除漫畫
  searchMangas, // 搜尋漫畫
  filterByStatus, // 依狀態篩選
  sortMangas, // 排序
} = useMangaStore();
```

## 📱 響應式設計

### 桌面裝置 (≥ 1024px)

- 漫畫卡片: 3-4 欄網格
- 表單: 雙欄布局
- 側邊篩選面板

### 平板裝置 (768px - 1023px)

- 漫畫卡片: 2 欄網格
- 表單: 單欄布局
- 可摺疊篩選面板

### 行動裝置 (< 768px)

- 漫畫卡片: 單欄列表
- 表單: 堆疊布局
- 底部篩選抽屜

## 🎨 設計規範

### 色彩系統

遵循專案的莫蘭迪色系:

- **主色**: `#D4A5A5` (柔和玫瑰粉)
- **輔色**: `#9C8AA5` (柔和紫灰)
- **強調色**: `#A5B9C4` (柔和藍灰)

### 字體

- **標題**: Press Start 2P (像素字體)
- **內文**: Space Mono (等寬字體)

### 元件樣式

- 使用 `.pixel-card` 類別建立卡片
- 使用 `.pixel-button` 類別建立按鈕
- 圓角: `rounded-pixel-sm/md/lg/xl`
- 陰影: `shadow-pixel`
